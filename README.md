# 🏓 Pong

Una rivisitazione del classico videogioco **Pong**, sviluppata in Java come progetto scolastico, in coppia con un compagno di classe. [@nokira](https://github.com/nomeutente)

## 📖 Descrizione

Il progetto ricrea il gameplay originale di Pong: due racchette controllate dai giocatori si sfidano a colpire una pallina che rimbalza sullo schermo, con l'obiettivo di far segnare punti mandando la pallina oltre la racchetta avversaria.

## 🛠️ Tecnologie

- **Java** — linguaggio di sviluppo
- **Java Swing/AWT** — per la grafica e la gestione dell'interfaccia

## 🚀 Come avviare il progetto

1. Clona la repository:
   ```bash
   git clone https://github.com/Gallogc/Pong.git
   ```
2. Apri il progetto con il tuo IDE Java preferito (es. Eclipse, IntelliJ IDEA).
3. Esegui la classe principale (main) per avviare il gioco.

## 🎮 Come si gioca

- Ogni giocatore controlla una racchetta tramite tastiera.
- Lo scopo è respingere la pallina evitando che superi la propria racchetta.
- Vince chi raggiunge per primo il punteggio prestabilito.

## 👥 Autori

Progetto realizzato in coppia con un compagno di classe, come lavoro scolastico.
